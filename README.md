# Edward McCann

Website for Edward McCann Architecture, an RIBA Chartered and ARB registered
practice in Hackney, East London. Rebuild of
[edwardmccann.studio](https://edwardmccann.studio/) for the client, replacing a
2018 concrete5 site.

Staging: <https://edward-mccann.lab.mahlangu.dev> (not indexed)

## Stack

Next.js 16 (App Router) with TypeScript and CSS Modules. No UI framework and no
utility CSS: the design is bespoke and typographic, and every token lives in
`app/globals.css`. Deployed as a standalone Docker image on a self-hosted
Coolify server. Imagery is pre-processed and served from Backblaze B2, so the
app server never optimises an image at request time.

## Layout

```text
app/           routes: / (selected), /index (archive), /projects/[slug],
               /practice, /press, /contact, plus sitemap, robots and OG image
components/    the design system in use: Wordmark, Plate, ProjectHero,
               IndexTable, ScrollProgress, Datelines, header and footer
content/       the site's data: facts.json is authored, text.json and
               figures.json are generated by the tools below
lib/           content assembly and media URL building
tools/         re-runnable scripts (see below)
docs/          the working briefs, and the content confirmation list
design-intelligence/  the audit of the legacy site that informed the redesign
```

Legacy `/projects/<slug>` URLs are preserved exactly, so all 27 existing project
links keep working. Only `/about` needed a redirect, to `/practice`.

## Working on it

```bash
npm install
npm run dev
```

`dev` wraps Doppler, so secrets are injected and never written to disk. The
quality gate is the same one CI runs:

```bash
npm run check
```

## Content pipeline

Content is committed structured data rather than a CMS, so the site builds
statically and has no runtime dependencies. Regenerate it with:

```bash
npm run content:figures   # per-project image lists from ../site-archive
npm run content:text      # project prose, with source defects repaired
npm run media:publish     # process to AVIF and JPEG, upload to B2
```

`content/facts.json` is hand-authored and is the file to edit when the practice
confirms places, years, statuses and credits.

## Infrastructure

- **Secrets** live in Doppler, project `edward-mccann`. Nothing is read from
  `.env` files.
- **Media** is in the Backblaze B2 bucket `edward-mccann-media`, public-read,
  written by a key scoped to that bucket alone. `tools/b2-provision.mjs` created
  it; `tools/b2-inventory.mjs` verifies it.
- **Deploy** is `tools/coolify-deploy.mjs`, which is idempotent: it provisions
  the project and application if absent, then triggers a build.
- A Backblaze MCP server is registered in `.mcp.json`, launched through Doppler
  so no credential is stored on disk.
